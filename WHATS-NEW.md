# What's new

A plain-language history of the app, newest first. Each update has a version number. A bigger first number means a bigger change.

## Newest changes

These are in the app now and haven't been given a version number yet.

### New
- **DC Summary from the Plan Review Document.** Load a Plan Review Document and get one clean table of how the plan is set up: eligibility, vesting, contributions, loans and more. Useful when the plan isn't built in the system yet.
- **What's new.** This page. The app now keeps a running history of every update.
- **Updated training video** showing all of version 1.0.

## Version 1.0 — November 16, 2026
**Workbook Studio becomes the official team app.**

### New
- **One app for everyone.** Workbook Studio is now the single app the team uses.
- **Practice copy** with a made-up case already loaded, for training and demos.
- **Merger compare.** Turn a merger compare PDF into a spreadsheet in one step. The file never leaves your computer.
- **Plan documents.** Drop in a plan document and the app pulls out the key plan details for you.
- **OneAmerica FINAL workbooks** can now be read, with a warning if the loan numbers don't add up.
- **How it's read.** See exactly where each column comes from in the vendor's file.

### Better
- **Every update is now checked automatically** against sample files for every vendor, so a fix for one vendor can't quietly break another.

## Version 0.11 — November 16, 2026
**More control over exports.**

### New
- **Save sheets as separate files.** Each supporting sheet can save as its own file, next to the full workbook.
- **Pick your save folder.** Choose where exports go, and the app remembers it.
- **Loan reports for Alerus and Ameritas.**

## Version 0.10 — November 9, 2026
**Alerus is added.**

### New
- **Alerus files** can now be read, with the clean-up done for you (leading zeros, blank dates, code descriptions).

### Fixed
- Alight files sent one per record type now read correctly.
- Roth basis numbers are corrected for vendors that send their own.

## Version 0.9 — November 6, 2026
**Prior-year totals.**

### New
- **957 Prior Year.** Read the 957 valuation PDF and get each person's yearly totals, checked against the plan total.
- **Roth rollover split** in the Roth Basis sheet.

## Version 0.8 — November 2, 2026
**Smoother loading and a fuller preview.**

### New
- **Empower Roth Basis.**
- **Add more files any time** without losing the ones already loaded.
- **The preview shows everything** that will be in the export.

### Better
- Fund codes now match across every sheet.
- The breakdown shows sources and funds side by side.
- Paychex loans are listed once per person and loan.

## Version 0.7 — October 29, 2026
**Smarter mapping checks.**

### New
- **Conversion type.** Export asks whether it's Cash, Mapping, Transfer in kind, or a mix, and builds the right sheets.
- **Split funds.** A fund going to several new funds is divided correctly, down to the penny.
- **Older Excel mapping files** (.xls) are accepted.

### Better
- **Mapping checks look at the actual data,** not just the headings, and explain what's wrong.
- **A fund missing from the mapping now stops you** instead of quietly going to cash.
- The fund picker is clearer about what still needs attention.

## Version 0.6 — October 23, 2026
**Alight is added.**

### New
- **Alight files** can be read, with names filled in from Alight's data dictionary and a count check.

## Version 0.5 — October 17–19, 2026
