# Data Parser Workspace Notes

This workspace is organized around `Main File.html`, the live single-file Workbook Ingestion Console app.

## Folder map

- `../Main File.html` - current app source.
- `operator-guides/` - user-facing procedure guide deliverables for the app.
- `design-explorations/` - visual mockups, landing-page experiments, and generated design assets.
- `superpowers/` - planning/spec notes from prior app work.
- `../design/` - Studio notes and instructions for visual polish or alternate looks.
- `../garage/` - feature, restructuring, and validator expansion notes.
- `../archive/app-versions/` - historical app snapshots kept for rollback/reference.

## Cleanup rule

Keep the root focused on the live app and active configuration. Put generated docs, design experiments, and historical snapshots in the folders above so future validator work stays easier to reason about.
