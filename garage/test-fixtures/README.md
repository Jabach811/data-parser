# Mapping Validation Test Fixtures

These files are generated by `../scripts/build-mapping-fixtures.mjs`.

## Files

- `1-12345 Mapping Validation Import Fixture.xlsx` - Principal-style import workbook. Use with the `PRINCIPAL` source in folder mode.
- `Mapping Validation - Valid Messy Fixture.xlsx` - mapping workbook that should pass the current validator while producing rich review/reconciliation material.
- `Mapping Validation - Invalid Row Errors Fixture.xlsx` - mapping workbook that should fail current row-level validation.
- `Mapping Validation - Invalid Header Fixture.xlsx` - mapping workbook that should fail required-header validation.
- `Mapping Validation - Missing Tabs Fixture.xlsx` - workbook that should fail because it is missing the expected mapping tabs.

## Coverage Intent

The fixture pack is designed for improving review/audit output around mapping validation.

It includes:

- matched source and fund codes
- missing source and fund codes from the import side
- duplicate source mapping rows
- duplicate fund mapping rows
- mapping-only rows
- ignored fund rows where descriptor is `NA`
- Source Mapping rows with blank `SRC I`
- Source Mapping `SRC I` values not found in the embedded Source I section
- Source Mapping translation codes not found in Source I
- Source I duplicate `SRC_I` values
- Source I duplicate translation codes
- Source I malformed `SRC_I` values
- Source I advisory cases for blank source type and blank support columns
- hard source row errors for B, C, D, G, H, K, L, M, and Q
- hard fund row errors for B, C, D, E, F, Q, and T
- required-header failures for Source Mapping and Fund Mapping
- missing-tab failures for Source Mapping and Fund Mapping

## Basic Manual Test Flow

1. Open `../../Main File.html`.
2. Select `PRINCIPAL` as the source.
3. In folder mode, select a folder containing `1-12345 Mapping Validation Import Fixture.xlsx`.
4. Upload `Mapping Validation - Valid Messy Fixture.xlsx` as the mapping file.
5. Review validation warnings and reconciliation output.
6. Upload `Mapping Validation - Invalid Row Errors Fixture.xlsx` as the mapping file.
7. Confirm the validator reports row-level failures.
8. Upload `Mapping Validation - Invalid Header Fixture.xlsx`.
9. Confirm the validator reports required-header failures.
10. Upload `Mapping Validation - Missing Tabs Fixture.xlsx`.
11. Confirm the validator reports missing-tab failures.
